# 프로젝트 아이디어 기획서 

## 1. 프로젝트 이름 (Project Name)
**"Seoul Real Estate Insights - My Local Dashboard" (가칭: 서울 부동산 로컬 대시보드)**

## 2. 프로젝트 배경 및 목적 (Background & Objective)
- **배경**: 네이버 부동산의 정보는 방대하나 본인의 자본금과 조건에 맞는 데이터를 필터링하고 직관적으로 파악하기엔 불편함이 큽니다.
- **목적**: Python으로 로컬에서 데이터를 직접 수집(크롤링)하고 이를 CSV 파일로 저장한 뒤, 오직 *나만 보기 위해* 지도 기반 프론트엔드로 시각화하는 강력한 1인 전용 분석 도구를 구축합니다. 서버 호스팅 등의 유지보수 비용과 인프라 관리가 들어가지 않습니다.

## 3. 서비스 타겟 사용자 (Target Audience)
- **나 자신 (1인 사용자)**: 관심 있는 서울 지역의 매물을 발굴하고, 실제 투자 또는 내 집 마련에 활용할 수 있도록 지도와 대시보드 구성을 필요로 하는 개인

## 4. 핵심 기능 (MVP - Minimum Viable Product)
- **로컬 파일 자동 동기화**: 크롤러가 바탕화먼 프로젝트 폴더(`data/`)에 CSV를 생성하면, 로컬 프론트엔드가 이를 즉각 화면에 불러와 최신 시세 반영
- **구/동 단위 평당가 히트맵 시각화**: 수집된 CSV 데이터를 바탕으로 서울 지도 위에서 행정동 혹은 구별로 평당 단가(매매/전세)를 색상(히트맵)으로 렌더링
- **나만의 자본금 필터링**: 내가 가진 자본금 한도를 입력하면 CSV 데이터에서 조건에 맞는 매물(핀)만 지도에 필터링되어 출력
- **전세가율 및 갭투자 분석**: 매매가와 전세가 차이가 적은 단지들을 화면에 리스트업하고 바로 분석할 수 있도록 대시보드 제공

## 5. 기대 효과 (Expected Impact)
- 비용 제로(0): 서버 호스팅 및 DB 구축 없이 내 PC에서 빠르고 가볍게 시세를 업데이트하고 시각화할 수 있음
- 필요한 조건(예: 나의 자본금, 평수, 갭투자 여건)에 맞춰 네이버 부동산에선 볼 수 없는 직관성을 지도 위에서 확인 가능
